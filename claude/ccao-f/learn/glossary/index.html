    Glossary

    Plain-English definitions of the 36 key terms in the CCAO-F learning guide, each linked to the lessons that teach it.

    Written and maintained by Prakash Sridharan, Claude Certified Architect

    ABCDEFGHILMPRSTUVW

    A

    Agent

    A system in which a model uses tools in a loop to reach a goal, choosing its own next steps instead of following a fixed path set in code.

    Also: agents, AI agent

    Lessons 3.2 Choosing a Model and Effort Level4.2 Deciding What to Delegate5.3 Writing Instructions That Hold

    AI Fluency

    Anthropic's framework for working with AI effectively, efficiently, ethically and safely, built on four competencies: Delegation, Description, Discernment and Diligence.

    Also: 4Ds, 4D Framework, 4D framework

    Lessons 1.1 Building a Prompt That Fits the Job2.1 Is This Output Fit for Purpose?2.3 How Much Review Is Enough?

    Artifacts

    Standalone pieces of content in claude.ai, such as documents, code, diagrams or small apps, shown in a panel beside the chat, where they can be edited, reused and shared.

    Lessons 2.4 Adapting Output and Choosing the Format3.1 Choosing the Right Capability

    B

    Bias

    A systematic skew in output, such as favoring certain groups, viewpoints or answer positions. Found by testing varied inputs and reviewing the results.

    Also: biased

    Lessons 2.2 Catching Hallucinations Before They Ship6.3 Policy, Ethics and Diligence

    C

    Citations

    References from Claude's answer to the exact source passages behind it, so a reader can check each claim.

    Also: citation, cite sources

    Lessons 2.2 Catching Hallucinations Before They Ship3.1 Choosing the Right Capability5.1 Configuring a Project

    Code execution tool

    A tool that lets Claude run code in a sandbox to analyze data, do calculations and create files.

    Also: code execution

    Lessons 1.2 Breaking Big Deliverables into Steps3.1 Choosing the Right Capability4.1 From Question to Actionable Plan

    Connectors

    Integrations that give Claude access to outside apps and data, such as Google Drive, Gmail or a company's own systems, so it can search and use them in a chat.

    Also: connector

    Lessons 3.1 Choosing the Right Capability4.3 Designing Repeatable Workflows5.2 Connectors and Knowledge Sources

    D

    Delegation

    The AI Fluency competency of deciding what work to give to AI, what to keep, and how to split it, based on the goal, the task and what the tool can do.

    Lesson 4.2 Deciding What to Delegate

    Description

    The AI Fluency competency of telling AI clearly what you need: the outcome, the process to follow and how it should behave.

    Lessons 1.1 Building a Prompt That Fits the Job4.4 Explaining Claude to Stakeholders

    Diligence

    The AI Fluency competency of taking responsibility for AI-assisted work: choosing tools with care, being open about AI's role and checking the work before it is shared.

    Lessons 2.3 How Much Review Is Enough?6.3 Policy, Ethics and Diligence

    Discernment

    The AI Fluency competency of judging AI output, its reasoning and its behavior critically, for accuracy and fit.

    Lesson 2.1 Is This Output Fit for Purpose?

    E

    Effort

    A request setting that tells the model how much reasoning and how many tokens to spend, trading answer quality against speed and cost.

    Lesson 3.2 Choosing a Model and Effort Level

    Escalation

    Routing a case from the automated system to a person, triggered by rules such as low confidence, high value, a policy exception or the customer asking for one.

    Also: escalate, escalated, escalates

    Lessons 2.3 How Much Review Is Enough?6.1 Is This Use Case Appropriate?6.3 Policy, Ethics and Diligence

    Evaluation (eval)

    A repeatable test of a model, prompt or agent against a set of cases with expected outcomes, scored by code, by people or by a model. Used to compare versions and catch regressions.

    Also: eval, evals, evaluation, evaluations

    Lessons 1.2 Breaking Big Deliverables into Steps2.1 Is This Output Fit for Purpose?

    F

    File creation

    A claude.ai capability in which Claude creates and edits files such as spreadsheets, documents and slide decks, using code execution behind the scenes.

    Lessons 2.4 Adapting Output and Choosing the Format3.1 Choosing the Right Capability

    G

    Grounding

    Telling Claude to base its answer only on material you supply, and to say plainly when that material does not cover the question.

    Also: grounded

    Lessons 1.1 Building a Prompt That Fits the Job2.2 Catching Hallucinations Before They Ship5.4 When a Configuration Drifts

    Guardrail

    A check outside the model's own judgment that blocks or corrects unsafe or invalid actions, such as input validation, an allow list or a hook.

    Also: guardrails

    Lessons 1.2 Breaking Big Deliverables into Steps5.3 Writing Instructions That Hold

    H

    Hallucination

    A confident statement that is not supported by the source material or by fact. Reduced by grounding answers in supplied documents, asking for quotes or citations, and allowing the answer "I don't know".

    Also: hallucinate, hallucinated

    Lesson 2.2 Catching Hallucinations Before They Ship

    Human in the loop (HITL)

    A design in which a person reviews or approves certain actions or outputs before they take effect, usually the high-impact or low-confidence ones.

    Also: human-in-the-loop, HITL, human review, human approval

    Lessons 2.3 How Much Review Is Enough?4.2 Deciding What to Delegate6.1 Is This Use Case Appropriate?

    I

    Incognito chat

    A claude.ai chat that is not saved to your chat history and does not use or add to memory.

    Also: incognito

    Lessons 3.1 Choosing the Right Capability3.3 Managing Context and Memory6.2 Protecting Sensitive Data

    Iteration

    Improving a prompt or an output over several rounds, changing one thing at a time and checking the effect of each change.

    Also: iterate, iterating, iterative

    Lessons 1.3 Diagnosing a Prompt That Underperforms2.3 How Much Review Is Enough?

    L

    Least privilege

    Giving an agent or tool only the permissions its task needs, which limits the damage a mistake or an attack can do.

    Also: least-privilege

    Lessons 5.2 Connectors and Knowledge Sources6.1 Is This Use Case Appropriate?

    M

    Memory

    A claude.ai feature that lets Claude remember useful context from past chats. You can view, edit or turn it off, and Projects keep their own memory.

    Lessons 3.3 Managing Context and Memory5.1 Configuring a Project5.4 When a Configuration Drifts

    Model tiers (Haiku, Sonnet, Opus)

    Claude comes in tiers: Haiku for fast, low-cost, high-volume work, Sonnet as a balanced default, and Opus for the hardest reasoning. Choosing per task balances quality, speed and cost.

    Lesson 3.2 Choosing a Model and Effort Level

    P

    Precision and recall

    Precision is the share of flagged items that really are positive; recall is the share of real positives that were flagged. Raising one usually lowers the other.

    Lessons 1.3 Diagnosing a Prompt That Underperforms2.1 Is This Output Fit for Purpose?2.2 Catching Hallucinations Before They Ship

    Project instructions

    Instructions set once on a claude.ai Project that apply to every chat in it, such as the audience, tone or format to use.

    Lessons 3.3 Managing Context and Memory5.1 Configuring a Project5.3 Writing Instructions That Hold

    Project knowledge

    The files and text added to a claude.ai Project, which every chat in that Project can use.

    Lessons 3.3 Managing Context and Memory4.3 Designing Repeatable Workflows5.1 Configuring a Project

    Projects

    Workspaces in claude.ai that group related chats with shared instructions and a knowledge base of files available to every chat in them.

    Lessons 3.1 Choosing the Right Capability3.3 Managing Context and Memory5.1 Configuring a Project

    Prompt template

    A reusable prompt with fixed instructions and placeholders for the parts that change, so a team gets consistent results from the same kind of request.

    Also: prompt templates, template, templates

    Lessons 1.3 Diagnosing a Prompt That Underperforms3.1 Choosing the Right Capability5.4 When a Configuration Drifts

    R

    Research

    A claude.ai feature in which Claude runs many searches across the web and connected sources and returns a report with citations. It takes longer than a normal answer.

    Lessons 2.2 Catching Hallucinations Before They Ship3.1 Choosing the Right Capability4.1 From Question to Actionable Plan

    S

    Sandboxing

    Running commands in an isolated environment with limits on file system and network access, so an agent can act with fewer approval prompts at lower risk.

    Also: sandbox, sandboxed

    Lesson 6.2 Protecting Sensitive Data

    Skill

    A folder with a SKILL.md file of instructions, plus optional scripts and resources, that Claude loads only when a task needs it. Skills work in Claude Code, the API and claude.ai.

    Also: skills, Agent Skills, SKILL.md

    Lessons 4.3 Designing Repeatable Workflows5.1 Configuring a Project5.4 When a Configuration Drifts

    T

    Training cutoff

    The date after which a model has no knowledge from its training. Anything newer has to come from web search, Research or documents you provide.

    Also: knowledge cutoff

    Lessons 2.2 Catching Hallucinations Before They Ship3.1 Choosing the Right Capability

    U

    Usage Policy

    Anthropic's rules on what Claude may and may not be used for, which apply to every product and user.

    Also: Acceptable Use Policy, Usage Policies

    Lesson 6.1 Is This Use Case Appropriate?

    V

    Verification

    Checking AI output against a trusted reference before it is used, such as the source documents, known data or an expert, with more checking where the stakes are higher.

    Also: verify, verified, fact-check, fact-checking

    Lessons 1.2 Breaking Big Deliverables into Steps2.2 Catching Hallucinations Before They Ship4.3 Designing Repeatable Workflows

    W

    Web search

    A claude.ai feature that lets Claude look up current information on the internet and cite where it came from.

    Lessons 1.3 Diagnosing a Prompt That Underperforms2.2 Catching Hallucinations Before They Ship3.1 Choosing the Right Capability
