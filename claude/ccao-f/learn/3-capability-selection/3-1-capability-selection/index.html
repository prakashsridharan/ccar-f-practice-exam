    Choosing the Right Capability

    Exam skillCapability Selection

    Analyzing a work task against the available Claude capabilities, including chat, Projects, Artifacts, research, code-executed analysis, Skills, connectors, and memory, and selecting the combination that best accomplishes the task.

    Pick capabilities from what the task needs. Chat for one-offs, Projects for recurring context, Artifacts and file creation for deliverables, web search or Research for current information, code execution for exact numbers, Skills for repeatable procedures, connectors for live data, and memory for continuity.

    Written and maintained by Prakash Sridharan, Claude Certified Architect

    On this pageWhat you need to knowIn the examCheck your understandingApply itSources

    What you need to know

    Before writing a prompt, decide where and with what you will work. The capability choice sets the ceiling on what the session can produce.

    What each capability is for

    CapabilityUse it whenNot for
    ChatOne-off questions and draftsWork you will repeat with the same background
    ProjectsRecurring work with stable context: instructions plus a knowledge base used by every chat in itA single reply
    ArtifactsSubstantial content to edit or reuse; small interactive toolsQuick answers
    Web searchA quick current factDeep multi-source investigation
    ResearchA cited report from many searches that build on each other (takes minutes, uses more of the plan)Single facts
    Code execution and file creationExact calculations, cleaning data, producing real Excel, Word, PowerPoint or PDF filesWriting prose
    SkillsA repeatable procedure or template applied the same way every time, by anyoneOne-off tasks
    ConnectorsReaching live data in tools you can already access, such as Google Drive, Gmail and CalendarPublic web content
    MemoryRecurring facts about you and your work carried across chatsFirm rules, documents, procedures

    Combine them for real workflows

    A quarterly funder report might use a Project (requirements and template), code execution (outcome metrics), Research (sector context with citations) and file creation (the funder's Word template). Name the need for each step, then the capability.

    Decision rule
    The three-question Project test

    Does the task recur? Is the background context the same each time? Is the output format consistent? If at least two answers are yes, a Project usually repays its setup within a few sessions.

    Boundaries to remember

    • Connectors work within your own permissions. Each connector has defined actions, may ask for approval before acting, and admins can restrict or disable them.
    • Built-in knowledge stops at a training cutoff; recent events need search or Research.
    • Skills need code execution and file creation turned on, and they live at account level, so a Skill can be used in any Project.
    Exam trap
    Configuration for its own sake

    A one-off reply to a supplier does not need a Project or a new Skill. Overbuilding wastes the time the tool should save.

    In the exam

    Items describe a task and ask which capability or combination fits. Read for the need: recurring context, current information, exact numbers, a real file, a fixed procedure across people, live private data, or continuity. Distractors use Research for private data, memory as a document store, incognito where context is needed, or a plain chat for recurring work.

    Check your understanding

    Question 1

    A director needs competitor product launches from the last 60 days, with sources. Which capability fits?

    Show answer

    Answer: A. Recent, multi-source findings need live sources and citations.

    Question 2

    Recruiters produce offer letters in a fixed template, but layouts vary and clauses get missed. What fixes consistency?

    Show answer

    Answer: D. A Skill applies the same procedure for everyone.

    Question 3

    A manager wants Claude to summarize the latest project plan in the team's Google Drive. Which fits?

    Show answer

    Answer: B. Connectors reach private data the user can already access.

    Apply it: Choose capabilities for Fairhaven

    Exercise · about 15 minCase: Fairhaven Unified School District

    The communications office wants help with three tasks: (A) a monthly parent newsletter in English and Spanish built from the district events calendar in Google Calendar, in a fixed template; (B) a one-time reply to a reporter's question about the bus schedule, with the schedule PDF at hand; (C) a cited overview of how other districts handled cell-phone policies this year.

    1. Choose the capabilities for each task.
    2. Justify each choice in one line.
    3. Name one capability you would not use for each, and why.
      Done when: each choice maps to a stated need.
    Check your work
    Show model answer

    A. A Project (template, tone rules, bilingual requirement in instructions), the Calendar connector (live events) and a Skill or file creation for the newsletter template. Not memory: rules and templates need dependable configuration.

    B. A plain chat with the PDF attached. One-off, source in hand. Not a Project: no recurrence.

    C. Research, then open and check the key citations. Current, multi-source and cited. Not built-in knowledge: policies changed this year, after the training cutoff.
