    Diagnosing a Prompt That Underperforms

    Exam skillPrompt Diagnosis and Iteration

    Analyzing an underperforming prompt and its output to attribute the deficiency to a specification gap, including missing context, ambiguous instruction, absent constraint, or wrong strategy for the task type, and judging when to iterate, restart, or change approach.

    Read a disappointing output as evidence. Name the specification gap it points to (missing context, ambiguous instruction, absent constraint or wrong strategy), change that one thing, and know when to stop iterating, restart or change approach.

    Written and maintained by Prakash Sridharan, Claude Certified Architect

    On this pageWhat you need to knowIn the examCheck your understandingApply itSources

    What you need to know

    When output disappoints, two habits waste time: giving up ("Claude can't do this") and thrashing (changing many things at once). Diagnosis replaces both: read the output, name the gap, fix that component.

    Symptoms point to causes

    SymptomLikely gapFix
    Generic, could be about anyoneMissing contextAdd audience, facts, purpose
    A reasonable answer to a different questionAmbiguous instructionSharpen the verb and scope ("check whether each conclusion follows from the tables")
    Right content, wrong length, tone or shapeAbsent constraintAdd the limit, tone or format
    Good explanation, wrong numbersWrong strategy: prose arithmeticUse code execution
    Confident but out of dateWrong strategy: no current sourceWeb search or Research
    Narrow, safe brainstormWrong strategy: over-constrainedLoosen, then filter later
    Correct early, drifting later in a long chatContext degradationRestart with a summary

    Change one thing at a time

    Keep the parts that work and change the component the output points to. If you rewrite the whole prompt, you lose what worked and cannot tell which change helped.

    Example
    Three rounds, then stop

    Round 1 added the cause and the new date to a delay notice. Round 2 added a tone limit. Round 3 asked only for a better subject line. Round 4 would have changed a single word, so the writer finished by hand.

    When to stop, restart or change approach

    • Stop iterating when rounds produce marginal change; finish with a manual edit.
    • Restart with a summary when a long conversation has degraded.
    • Change approach when the same failure survives several rounds. Nine rounds of fixing one format element and breaking another show that a fixed multi-step format belongs in a Skill or template, not in more prompting.
    • Reshape the task when it asks for something no prompt can deliver, such as an exact future sales figure. Ask for scenarios and ranges instead.
    Exam trap
    Bigger model first

    Switching to the most capable model is the expensive move and rarely the fix for a specification gap. A stronger model cannot supply facts the request never contained.

    In the exam

    Items show a prompt, its output and the author's real goal. Name the gap from the evidence: first response wrong (specification), numbers wrong (strategy), outdated facts (strategy), drifting late (context), repeated failure on a fixed format (approach). Distractors switch models, regenerate, rewrite everything or add adjectives.

    Check your understanding

    Question 1

    A pipeline summary is fine except that it runs two pages; half a page was wanted. What fits?

    Show answer

    Answer: B. Fix the one failing component and keep what works, so the effect is clear.

    Question 2

    "Review this report" returned grammar comments; the author wanted the logic checked. Which gap?

    Show answer

    Answer: D. "Review" allows several readings; the task must say what to check.

    Question 3

    After nine rounds, a contract summary still breaks one template rule each time. What is the best conclusion?

    Show answer

    Answer: A. Repeated failure on a fixed procedure signals a change of approach, not more rounds.

    Apply it: Diagnose Fairhaven's quiz prompt

    Exercise · about 15 minCase: Fairhaven Unified School District

    Ms. Rivera asked: "Make a quiz on chapter 4 of our novel." She got 25 recall questions about minor characters, too hard for her Grade 8 class, with no answer key. She wanted 10 questions on theme and character motivation for a 20-minute warm-up, with answers.

    1. Name each gap and the component it belongs to.
    2. Write the improved request.
    3. Say what you would do if round two still misses on one element.
      Done when: each fix targets a named gap.
    Check your work
    Show model answer

    1. Gaps.

    • Purpose and focus (theme and motivation, not recall): missing context and a vague task.
    • Grade level: missing context.
    • Count and time (10 questions, 20 minutes): absent constraints.
    • Answer key: missing output format.

    2. Improved request. "For a Grade 8 English class that has just read chapter 4 of the novel (attached), write 10 questions for a 20-minute warm-up. Focus on theme and characters' motivations, not plot recall. Mix 6 short-answer and 4 multiple-choice questions at a Grade 8 reading level. Format: numbered questions, then an answer key with one-sentence explanations."

    3. If one element still misses (for example, the multiple-choice questions are too easy), keep the rest of the request and change only that instruction, for example "make the multiple-choice distractors plausible misreadings of the chapter." Stop when changes become marginal and finish by hand.
