    CCDV-P Learning Guide

    Claude Certified Developer - Professional (exam guide 1.0)

    Twenty-five short lessons, one for each skill in the CCDV-P exam guide 1.0 (November 2026), grouped by the eight exam domains. Each lesson explains the operating decisions the skill asks you to make in a live Claude system, the traps that catch candidates, and where to read more in Anthropic's documentation.

    Written and maintained by Prakash Sridharan, Claude Certified Architect

    lessons complete
    Before the examCheat sheetThe whole Developer Professional guide on three printed pages or fewer. For each domain, one line to remember and an "if the question says this, pick that" table, plus the facts worth memorising. Read it the day before the exam.
    Domain 117% of the exam

    Advanced Agent Architecture and Orchestration

    Orchestrating multi-agent systems that survive production: supervisor and worker designs, context isolation and approval flows, durable state and checkpoints, choosing between workflows and agents from production data, and context and memory policies for long-running agents.

    4 lessons
    Domain 220% of the exam

    Production Integration, Reliability, and Knowledge Grounding

    Keeping high-volume Claude integrations reliable: retries, circuit breakers and fallbacks that tell rate limits from refusals and length stops, throughput and multi-tenant quotas, production MCP and change management, and retrieval and grounding at scale.

    4 lessons
    Domain 312% of the exam

    Observability and Production Monitoring

    Seeing what production Claude systems do: distributed traces for agent loops and tools, token, cost and cache metrics under privacy constraints, SLIs, SLOs and alerting for quality drift, and finding systemic issues in high-volume trace data.

    3 lessons
    Domain 410% of the exam

    Advanced Debugging and Incident Response

    Isolating the origin of complex failures among model output, harness, tools and data, including refusals and grounding failures, and leading incident response from triage and rollback to regression evaluations and postmortems.

    2 lessons
    Domain 512% of the exam

    Evaluation Engineering and Quality Assurance

    Building evaluation systems that gate releases: golden sets, regression suites and CI gates kept valid over time, LLM judges calibrated against human labels, and online quality measurement on live traffic.

    3 lessons
    Domain 68% of the exam

    Cost and Latency Optimization at Scale

    Controlling cost and latency across a fleet: cost models and forecasts, model routing and cascades, caching strategy and diagnostics, batch versus real-time economics, tenant budgets, time to first token, streaming, parallel tools and effort tuning.

    2 lessons
    Domain 711% of the exam

    Runtime Guardrails and Production Security

    Defending tool-using agents in production: layered guardrails, PII redaction, hooks and approval gates, sandboxing, prompt injection and exfiltration defenses, red teaming with OWASP and NIST guidance, workload identity, secrets and audit.

    3 lessons
    Domain 810% of the exam

    Agent Fleet Operations for Software Delivery

    Running fleets of coding agents: parallel agents on worktrees with merge strategy, verification and AI code review calibrated before it gates merges, unattended and event-driven runs, and organization-wide Claude Code configuration.

    4 lessons

    Every lesson ends with a short exercise set in one of four fictional companies. Their facts are on the case studies page.

    Ready to test yourself? The CCDV-P practice tests cover the same eight domains, with a rationale and documentation link for every question.

    Important Note

    These lessons are original study notes, written from the publicly available exam guide and Anthropic's public documentation. They contain no real exam content: live exam content is confidential, and every candidate agrees to keep it that way. This is an independent study aid and is not affiliated with or endorsed by Anthropic. Reading the lessons is not a guarantee of passing, so pair them with the practice tests and hands-on work operating Claude systems.
