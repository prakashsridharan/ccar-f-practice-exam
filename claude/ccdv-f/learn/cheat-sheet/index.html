    How to read a CCDV-F question

    Most items show code, a request, a trace, an error or a configuration with something wrong. Six habits pick the right answer:

    1. Find the layer. Integration code, configuration, tool, prompt or model: fix the one that failed.
    2. Classify before you retry. Transient (429, 529) or deterministic (400, max_tokens, refusal).
    3. Enforce outside the model. Hooks, permission rules, tool code, identity scope; prompts only guide.
    4. Simplest thing that works. Workflow before agent, built-in before custom, custom tool before MCP server.
    5. Measure, then change. Golden sets, calibrated judges, regression runs on every prompt or model change.
    6. Send less. Minimal data in, shaped tool results, cached stable prefixes.
