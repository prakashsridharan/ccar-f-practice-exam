    Developer Productivity & Operational Enablement

    Scaling Claude Code across an organization: packaging workflows as plugins with managed settings, configuring the Agent SDK and Claude Code permission modes, hooks and headless runs, and keeping humans accountable for AI-generated code.

    1. 7.1Packaging and Distributing Claude Code WorkflowsPackage a Claude Code workflow that works for one team as a plugin, distribute it through a marketplace and managed settings, and decide which controls are enforced centrally and which are left to teams.
    2. 7.2Configuring the Agent SDK and Claude CodeConfigure Claude Code and the Agent SDK for a team workflow (permission modes, deny rules, hooks, subagent definitions and headless or CI runs) so it stays inside its safety guardrails, including when nobody is watching.
    3. 7.3Accountability for AI-Generated CodeKeep people accountable for AI-generated code: put assistance where it helps, give Claude ways to verify its work, and keep a review discipline in which a named person understands and answers for what ships.
