    Claude Models, Prompting & Context Engineering

    Choosing the model tier that meets every binding constraint, diagnosing and revising system prompts, matching the prompting technique to the failure, and managing tokens, cache breakpoints, reasoning effort and long-running context.

    1. 2.1Selecting a Model TierSelect the model tier that satisfies every binding latency, cost and quality constraint for a workload, and explain why each rejected tier fails.
    2. 2.2Diagnosing and Revising System PromptsDiagnose the underspecification in a system prompt that causes degraded or inconsistent output, and choose the revision that constrains scope, format and behaviour without over-constraining legitimate variation.
    3. 2.3Choosing a Prompting TechniqueApply the prompting technique (zero-shot, few-shot, prompted reasoning or native thinking, structured output) that fixes an observed failure pattern for a task of stated complexity, without paying for tokens it does not need.
    4. 2.4Context Composition and Token EconomicsAnalyse a request's context composition and caching against a token budget and a call volume, and find where token use can fall without losing task-relevant information.
    5. 2.5Cache Breakpoints and Reusable PackagingPlace cache breakpoints and package reusable content (modular prompts or Skills) so stable content comes before dynamic content and reuse is maximised across the call pattern.
    6. 2.6Reasoning Effort and the Context LifecycleSpend reasoning where it changes the answer, and keep a long-running agent's context useful for hours with context editing, the memory tool and compaction, chosen by what the session must remember.
