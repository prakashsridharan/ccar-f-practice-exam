Anthropic's Claude certifications cover three roles. Claude Certified Associate - Foundations (CCAO-F, exam guide 1.1, effective 7 December 2026) is for business users who work with Claude at claude.ai: prompting, checking output, choosing features, building repeatable workflows and handling data responsibly. Claude Certified Architect has two levels: Foundations (CCAR-F, exam guide 1.0) and Professional (CCAR-P). CCAR-P comes in two versions here: Version 1.1 follows exam guide 1.1, which applies from 7 December 2026, and Version 1.0 follows the current guide 1.0 until then. Claude Certified Developer - Professional (CCDV-P, exam guide 1.0) is for engineers who operate Claude applications and agents in production. Each learning guide teaches every exam topic in a short lesson with check questions and a case-study exercise: 21 lessons for CCAO-F, 30 for CCAR-F, 39 for CCAR-P Version 1.1, 38 for Version 1.0 and 25 for CCDV-P. Each practice exam mirrors its official blueprint: questions are drawn in the same domain proportions as the real exam, every answer carries a full rationale, and each links to the relevant Anthropic documentation.

Frequently asked questions

Which certification should I start with?

If you use Claude at work for writing, analysis and everyday tasks rather than building with it, start with Associate - Foundations (CCAO-F): it covers prompting, checking output, Projects, Artifacts, connectors, workflows and responsible use. If you build with Claude day to day, start with Architect - Foundations (CCAR-F): it covers agents, tools, Claude Code and prompting. Architect - Professional (CCAR-P) adds solution design, evaluation, governance and stakeholder work, and suits architects who lead Claude projects. Developer - Professional (CCDV-P) is for engineers who run Claude systems in production: agent orchestration, reliability, observability, incident response, evaluation, cost and latency, security, and fleets of coding agents.

Which CCAR-P version should I use?

Use Version 1.0 if you sit the exam before 7 December 2026, and Version 1.1 for exams from that date, when Anthropic's exam guide 1.1 takes effect. Version 1.1 has 70 items, new domain weights and skills, and new topics such as deployment surfaces, Claude Managed Agents and prompt injection through MCP servers. See everything that changed on 7 December.

Do I need a Foundations certification before a Professional exam?

No, none of the exams has a prerequisite. The CCAR-P exam guide treats the Architect Foundations scope as assumed knowledge, and the CCDV-P guide recommends the Claude Certified Developer - Foundations certification as preparation (this site does not cover that exam yet).
