Claude Certification Learning Guides and Practice Exams

Learning guides and practice exams for the Claude Certified Architect certifications from Anthropic. Free, no sign-up.

Anthropic's Claude Certified Architect program has two levels: Foundations (CCAR-F) and Professional (CCAR-P). The learning guides teach every exam task (30 for CCAR-F, 38 for CCAR-P) in a short lesson with check questions and a case-study exercise. Each practice exam mirrors its official blueprint: questions are drawn in the same domain proportions as the real exam, every answer carries a full rationale, and each links to the relevant Anthropic documentation.
