Frequently asked questions

Which certification should I start with?

If you use Claude at work for writing, analysis and everyday tasks rather than building with it, start with Associate - Foundations (CCAO-F): it covers prompting, checking output, Projects, Artifacts, connectors, workflows and responsible use. If you build with Claude day to day, start with Developer - Foundations (CCDV-F): the Messages API, agents and the Agent SDK, Claude Code, prompts and context, tools and MCP, evaluation, cost and security. Architect - Foundations (CCAR-F) covers similar ground from the solution-design side: agents, tools, Claude Code and prompting. Architect - Professional (CCAR-P) adds solution design, evaluation, governance and stakeholder work, and suits architects who lead Claude projects. Developer - Professional (CCDV-P) is for engineers who run Claude systems in production: agent orchestration, reliability, observability, incident response, evaluation, cost and latency, security, and fleets of coding agents. Compare all five side by side: audience, format, fee and domain weights.

Which CCAR-P version should I use?

Use Version 1.0 if you sit the exam before 7 December 2026, and Version 1.1 for exams from that date, when Anthropic's exam guide 1.1 takes effect. Version 1.1 has 70 items, new domain weights and skills, and new topics such as deployment surfaces, Claude Managed Agents and prompt injection through MCP servers. See everything that changed on 7 December.

Do I need a Foundations certification before a Professional exam?

No, none of the exams has a prerequisite. The CCAR-P exam guide treats the Architect Foundations scope as assumed knowledge, and the CCDV-P guide recommends the Claude Certified Developer - Foundations (CCDV-F) certification as preparation.
