About the CCAR-F exam

The CCAR-F certification validates your ability to design, build and optimize AI-powered applications using Claude and the Anthropic platform. The real exam is 60 multiple choice questions in 120 minutes, delivered online proctored, and uses scaled scoring with a pass mark of 720 out of 1000.

Exam domains

  • D1 - Agentic Architecture & Orchestration (27%): the agent loop, stop_reason handling, task decomposition, subagent delegation and multi-agent coordination.
  • D2 - Tool Design & MCP Integration (18%): tool schemas, precise descriptions, actionable error messages, right-sized tool catalogs and exposing tools over MCP.
  • D3 - Claude Code Configuration & Workflows (20%): CLAUDE.md memory, custom slash commands, hooks, permission scoping, sessions and CI/CD integration.
  • D4 - Prompt Engineering & Structured Output (20%): JSON schemas via tool_use, required versus optional fields, validation and repair loops, and batching for cost.
  • D5 - Context Management & Reliability (15%): context window budgeting, compaction, preserving citations through summarization and recovering state after failure.

Ways to practice

  • Practice Test 1: a fixed set of 60 questions in the same proportions as the official blueprint, on a 120-minute timer, with flag-for-review and a score report broken down by domain. Your best and latest scores are kept in your browser, and an unfinished test can be resumed.
  • Random Mix: a new set of 60 questions drawn from the whole bank each time.
  • Study Mode: browse all 100 questions grouped by domain, reveal answers and rationales as you go, and filter to the areas you are weakest in.
